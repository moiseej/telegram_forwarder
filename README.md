# Telegram Forwarder

Бот отправляет текст и фотографии по коротким командам в темы Telegram-групп.
В каждой группе свои назначения; сообщения остаются внутри исходной группы.
Выделен из `modulepythonbot-main/apps/topic_forward`. Мост между чатами, Wanderer и Mini App сюда не входят.

## Возможности

- `/к текст`, `/ж текст`, `/и текст` — отправка в тему из конфигурации.
- Фото с такой командой в подписи — отправка фото и очищенной подписи.
- Команды можно менять; поддерживаются кириллица и `/к@ИмяБота`.
- Перед текстом добавляется `@username` автора или его имя.
- Закрытая тема открывается, после чего отправка повторяется один раз.
- Сообщения ботов и команды, адресованные другому боту, игнорируются.

Это новое сообщение от имени бота с подписью автора. Оригинал сохраняется.
Видео, документы, альбомы как единое целое, редактирование и удаление копий не поддерживаются.
Слишком длинный текст с подписью автора отклоняется с пояснением.
Ожидающие обновления Telegram при запуске не сбрасываются; восстановления полной истории и гарантированной доставки нет.

## Настройка из Telegram

1. Добавьте бота в нужную группу с темами и назначьте администратором.
   Для открытия закрытых тем дайте право управления темами.
2. Откройте тему назначения и от личного имени администратора отправьте `/bind к`.
3. В других темах повторите `/bind ж`, `/bind и` или задайте свои коды.
4. Теперь из любого места этой группы отправляйте `/к текст` или фото с подписью `/к текст`.

`/routes` показывает назначения текущей группы. `/unbind к` удаляет назначение.
Повторный `/bind к` в другой теме переназначает команду. `/help` показывает инструкцию.
Можно писать `/bind@ИмяБота к`, если в группе несколько ботов.

ID вручную вводить не нужно: группа и тема берутся из сообщения `/bind`.
Изменения доступны только действующим администраторам группы, права проверяются при каждой команде.
Анонимные административные команды не принимаются: отправьте их от личного имени.
Настройка в личке, обычных группах без тем и привязка общей темы не поддерживаются.
Код содержит 1–32 буквы/цифры/подчёркивания; до 50 назначений на группу.
Настройки применяются сразу, хранятся в SQLite и сохраняются после перезапуска.

## Docker

Создайте локальный файл `.secrets/bot_token.txt`, содержащий только токен бота.
Этот файл исключён из Git и контекста Docker-сборки. В контейнер токен передаётся
файлом Docker Compose secret; в образ и переменные окружения контейнера значение не попадает.

```powershell
python scripts/pipeline.py docker-build
python scripts/pipeline.py docker-test
python scripts/pipeline.py docker-check
python scripts/pipeline.py docker-up
python scripts/pipeline.py docker-status
```

Образ: `telegram-forwarder:local`. `docker-check` проверяет `getMe` и отсутствие webhook,
не отправляет сообщения и не читает очередь обновлений. `docker-test` работает без сети и токена.
У контейнера нет открытых портов, он работает непривилегированным пользователем.
База хранится в отдельном volume `routes`; перезапуск и пересборка образа её сохраняют.
Остановка: `python scripts/pipeline.py docker-down` (без удаления volume).
Не удаляйте volume, если назначения нужны. Не запускайте второй polling-процесс с тем же токеном.

## Локальный запуск

Требуется Python 3.10+.

```powershell
python scripts/pipeline.py setup
```

Задайте токен в окружении текущего процесса, затем запустите:

```powershell
$env:TOPIC_FORWARD_BOT_TOKEN="ваш токен"
python scripts/pipeline.py run
```

Также принимается `BOT_TOKEN`; `TOPIC_FORWARD_BOT_TOKEN` имеет приоритет.
`BOT_TOKEN_FILE` указывает файл токена и имеет приоритет над обеими переменными.
Токен не хранится в YAML. `.env` автоматически не загружается.
По умолчанию база находится в `data/routes.sqlite3`; путь можно задать через `FORWARDER_DB`.
Локальные данные, секреты, конфигурация и логи исключены из Git.

Для переноса старой конфигурации можно создать `config.yaml` командой
`python scripts/pipeline.py configure` и заменить примерные ID. Она импортируется
только при первом создании базы. Дальнейшие изменения делайте через Telegram.
В Docker старый YAML автоматически не копируется; настройте назначения через `/bind`.

## Проверки

```powershell
python scripts/pipeline.py test
```

Исполняемые тесты `unittest` проверяют конфигурацию, маршрутизацию, подписи, фото,
границы длины, повторную отправку, права администраторов, изоляцию групп и сохранность назначений.
Telegram заменён моками; токен и сеть не нужны.
Полные логи сохраняются в `artifacts/pipeline-logs/`.
