# Telegram Forwarder

Бот отправляет текст и фотографии по коротким командам в темы **одной Telegram-группы**.
Выделен из `modulepythonbot-main/apps/topic_forward`. Мост между чатами, Wanderer и Mini App сюда не входят.

## Возможности

- `/к текст`, `/ж текст`, `/и текст` — отправка в тему из конфигурации.
- Фото с такой командой в подписи — отправка фото и очищенной подписи.
- Команды можно менять; поддерживаются кириллица и `/к@ИмяБота`.
- Перед текстом добавляется `@username` автора или его имя.
- Закрытая тема открывается, после чего отправка повторяется один раз.
- Сообщения других чатов, ботов и команды, адресованные другому боту, игнорируются.

Это новое сообщение от имени бота с подписью автора. Оригинал сохраняется.
Видео, документы, альбомы как единое целое, редактирование и удаление копий не поддерживаются.
Слишком длинный текст с подписью автора отклоняется с пояснением.
Накопленные до запуска обновления пропускаются; восстановления истории и гарантированной доставки нет.

## Запуск

Требуется Python 3.10+.

```powershell
python scripts/pipeline.py setup
python scripts/pipeline.py configure
```

В созданном `config.yaml` укажите ID группы и темы для каждой команды.
Примерные ID в `config.example.yaml` не являются рабочей настройкой.
Добавьте бота в группу и предоставьте права читать сообщения, отправлять текст/фото
и управлять темами, если требуется открывать закрытые темы.
Для команд в подписях фото и кириллических команд бот должен получать обычные сообщения группы:
отключите privacy mode через BotFather или назначьте бота администратором.

Задайте токен в окружении текущего процесса, затем запустите:

```powershell
$env:TOPIC_FORWARD_BOT_TOKEN="ваш токен"
python scripts/pipeline.py run
```

Также принимается `BOT_TOKEN`; `TOPIC_FORWARD_BOT_TOKEN` имеет приоритет.
Токен не хранится в YAML. `.env` автоматически не загружается.
Локальный `config.yaml`, окружение и логи исключены из Git.
После изменения конфигурации перезапустите бота. Для одного токена запускайте один экземпляр polling.

## Проверки

```powershell
python scripts/pipeline.py test
```

Исполняемые тесты `unittest` проверяют конфигурацию, маршрутизацию, подписи, фото,
границы длины и повторную отправку. Telegram заменён моками; токен и сеть не нужны.
Полные логи сохраняются в `artifacts/pipeline-logs/`.
